:!sectids:

Variable can be made constant.

== Why is this an issue ?

Unlike variables, constant values are known at compile time and are injected as is in the code, requiring no runtime processing and therefore reducing the environmental footprint.

In Java, the `final` keyword only brings such an optimization in two cases :

- a **constant variable** (JLS 4.12.4) : a `final` variable of primitive or `String` type, initialized with a constant expression (JLS 15.29 : literals, operators, conditional expressions, casts and other constants). The compiler inlines its value and computes the expressions using it (`a + "b"` becomes `"ab"`), for local variables as well as for fields,
- a **`static final` field** : once its class is initialized, the JIT compiler trusts its value as a constant, whatever its initializer, and can optimize the code using it.

Therefore, this rule reports a variable that is never reassigned, not already `final` and either :

- of primitive or `String` type, initialized with a constant expression,
- or a `static` field with an initializer.

Everywhere else (parameters, objects, arrays, values computed at runtime by a method call or read from a field...), the bytecode is identical with or without `final` : the keyword only improves readability, which is out of the scope of this rule.

=== When can it be ignored ?

This rule should not be ignored.

== Non compliant examples

[source, java]
----
public class MyClass {

    private static final String PREFIX = "pre";

    private static int maxRetries = 3; // Noncompliant, static field never reassigned
    private static Logger logger = Logger.getLogger(""); // Noncompliant, static field never reassigned, whatever its initializer

    private String varDefinedInClassNotReassigned = "0"; // Noncompliant, String initialized with a constant expression but not reassigned
    private int timeoutInSeconds = 60 * 5; // Noncompliant, primitive initialized with a constant expression but not reassigned

    void localVariableNotReassigned() {
        String y4 = "10"; // Noncompliant, local variable initialized with a constant expression but not reassigned
        String fromConstant = PREFIX + "-suffix"; // Noncompliant, initialized with a constant expression

        logger.info(y4 + fromConstant + varDefinedInClassNotReassigned + timeoutInSeconds + maxRetries);
    }

}
----

== Compliant examples

[source, java]
----
public class MyClass {

    private static final int MAX_RETRIES = 3; // Compliant, already 'static final'
    private static final Logger LOGGER = Logger.getLogger(""); // Compliant, already 'static final'
    private static int counter = 0; // Compliant, reassigned in method

    private final String varDefinedInClassNotReassigned = "0"; // Compliant, 'final' keyword used
    private Object myNonFinalAndNotReassignedObject = new Object(); // Compliant, an object is not a constant : 'final' brings no optimization
    private String varDefinedInConstructorReassigned = "1"; // Compliant, reassigned in constructor

    public MyClass() {
        varDefinedInConstructorReassigned = "3";
        LOGGER.info(varDefinedInConstructorReassigned);
    }

    void parameterNotReassigned(String parameter) { // Compliant, 'final' on a parameter brings no optimization
        LOGGER.info(parameter);
    }

    void localVariableReassigned() {
        String y1 = "10"; // Compliant, reassigned below
        final String PI = "3.14159"; // Compliant, 'final' keyword used

        y1 = "titi";
        counter++;

        LOGGER.info(y1 + PI);
    }

    void valuesComputedAtRuntime() {
        String fromMethod = String.valueOf(counter); // Compliant, computed at runtime : not a constant
        int fromNonFinal = counter * 2; // Compliant, 'counter' is not final : not a constant expression
        Integer boxed = 42; // Compliant, a boxed type can't be a constant
        String[] values = {"a", "b"}; // Compliant, an array is never a constant
        byte[] buffer = new byte[1024]; // Compliant, an array is never a constant

        LOGGER.info(fromMethod + fromNonFinal + boxed + values.length + buffer.length + MAX_RETRIES
                + varDefinedInClassNotReassigned + myNonFinalAndNotReassignedObject);
    }

}
----

== Related SonarQube rules

Some native SonarQube rules may also apply to the code fixed by this rule :

- `S1170` : a `final` instance field initialized with a constant should be `static final`, to avoid duplicating its value in every instance,
- `S1444` : a `public static` field should be `final`,
- `S1312` : a logger should be `private static final`,
- `S115` : once `static final`, a field is a constant and should follow the naming convention of constants.
