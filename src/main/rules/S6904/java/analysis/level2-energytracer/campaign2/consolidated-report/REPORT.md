## How to read this, and what not to claim

- A result is worth quoting only when Welch **and** Mann-Whitney agree and Cliff's δ is at least small. Large sample sizes make tiny differences "significant" without making them relevant.
- Check the per-phase plots before trusting anything: a visible trend means the machine drifted during the campaign and the run should be repeated.
- These figures measure the client side only - no database engine, no network. They are a lower bound on the real saving.
